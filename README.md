# Koçluk Takip
Node 22.5+ gerekir, bağımlılık yoktur. Yerelde: `npm start` (http://localhost:3000), test: `npm test`.

## Yayınlama (Render, iPad'den)
1. GitHub'da yeni depo açıp bu klasördeki dosyaları yükleyin.
2. render.com → New → Blueprint → depoyu seçin (`render.yaml` otomatik okunur).
3. Bitince verilen https adresi sistemin adresidir.
Veriler `/data` diskindeki SQLite dosyasında tutulur; disk olmadan kayıtlar silinir. Düzenli yedek alın.
