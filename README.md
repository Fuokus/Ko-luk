# Koçluk Takip
Node 22.5+. Yerelde: `npm start` (SQLite, http://localhost:3000), test: `npm test`.
Canlıda `DATABASE_URL` ortam değişkeni verilirse PostgreSQL kullanılır (tablolar ilk açılışta otomatik oluşur).
Dosyalar: `server.js` (API/yetki), `db.js` (veri katmanı), `config.js` (ders listesi, net formülü), `index.html` (arayüz).
